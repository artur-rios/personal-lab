How I host and ship every kind of project. Anything with a running backend,
such as a .NET API or a Flutter web app, runs in containers on one self-hosted
server, deployed by yggdrasil, my own deploy manager. Everything that needs no
server, such as landing pages, static sites, documentation and libraries, is
published on free hosting instead. The series starts with how I decide which is
which, follows the self-hosted platform from the bare server to a deploy, and
ends with the projects that never touch it.
